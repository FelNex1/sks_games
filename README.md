# SKS Quest — Геймификация для ломбарда

## Описание проекта

Проект разработан в рамках хакатона. Это мобильное веб-приложение для сети ломбардов "СКС", которое превращает накопление бонусов в увлекательную игру.

## Функционал

- Ежедневные квесты (Слово дня, Сапёр, Колесо фортуны, Трейдер золота)
- Система бонусов и наград
- Прогресс и серия входов
- Адаптивный дизайн под мобильные устройства

## Технологии

- **Frontend:** Vue 3, Vite, Axios
- **Backend:** FastAPI, SQLite
- **Стили:** CSS (адаптив под мобильные устройства)

git clone https://github.com/FelNex1/sks_games.git
cd sks_games

cd frontend
npm install
npm run dev

Создай файл `README.md` в корневой папке `sks_games-main` и скопируй туда этот текст.

Затем добавь в Git:

```bash

git commit -m "Добавлен README.md"
```
